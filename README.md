## 📌 Project Overview

This project is a personal portfolio website developed as part of the **Synent Technologies Web Development and Designing Internship Program**.

The website showcases my personal profile, skills, projects, and contact information through a clean and responsive single-page design.

## 🎯 Objective

The objective of this task is to create a personal portfolio website using HTML and CSS to present personal information and technical skills in a professional way.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Responsive Web Design

## ✨ Website Features

The portfolio website includes:

* Header and navigation
* About Me section
* Skills section
* Projects section
* Contact section
* Footer
* Responsive design for different screen sizes

## 📱 Responsive Design

The website is designed to provide a suitable viewing experience on both desktop and mobile devices.
